# 💸 Smart Budget

> *"Set money aside today and let them grow for you overtime"*

Минималистично уеб приложение за автоматично разпределение на месечните приходи. Данните се съхраняват изцяло локално в паметта на устройството (`localStorage`), без външни сървъри.

🔗 **Линк към приложението:** [Отвори Smart Budget][https://...](https://bilyan8.github.io/smart-budget/)

## 📊 Разпределение на приходите

| Дял | Формула | Категория |
| :---: | :---: | :--- |
| **55%** | X * 0.55€ | 🏠 **Основни разходи** — наем, храна, сметки и транспорт |
| **5%** | X * 0.05€ | 😎 **Без угризения** — свободни средства за лични удоволствия |
| **10%** | X * 0.10€ | 💳 **Инвестиране / Кредит** — погасяване на задължения или инвестиции |
| **15%** | X * 0.15€ | 🎯 **Краткосрочни цели** — нова къща, кола, ваканция и др. |
| **15%** | X * 0.15€ | 🏛️ **Дългосрочно богатство** — инвестиране за дълъг период |
